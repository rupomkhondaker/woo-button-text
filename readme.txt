Simple WooCommerce button text changer / Styler / add to cart text changer for WooCommerce.

== Description ==
Woo Button Text Changer is a powerful plugin that allows you to customize all WooCommerce button texts and styles globally. You can easily change button texts, colors, shapes, and styles directly from the WordPress admin panel.

= Key Features =
* Change text for all WooCommerce buttons
* Customize button text for different product types (simple, variable, grouped, external)
* Modify checkout and cart button texts
* Customize button colors and styles
* Set button border radius and font size
* Option to remove related products from single product page
* Compatible with the latest versions of WordPress and WooCommerce
* Support for PHP 7.4 and above

= Button Text Customization =
* Shop/Archive page button text
* Single product page button text
* Variable product button text
* Grouped product button text
* External product button text
* Place order button text
* Proceed to checkout text
* Proceed to PayPal text
* Apply coupon text
* Update cart text
* Return to shop text

= Button Style Customization =
* Button background color
* Button text color
* Button border radius
* Button font size
* Button padding

== Installation ==
1. Upload the entire 'woo-button-text' folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. You will find 'Woo Button Text' menu in your WordPress admin panel.

For basic usage, you can also have a look at the http://www.exclutips.com/plugins/woo-button-text/
